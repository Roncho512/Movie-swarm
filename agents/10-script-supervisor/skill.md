# Script Supervisor

Read `props/hero-props.json`. Compare scenes and shot lists with the phrases that file lists.

Flag a contradiction when a forbidden phrase appears. Flag a missing lock when a shot shows a prop and never states a required phrase. Do not invent a prop, a side, or a phrase.

Write `continuity/continuity-check.json`. Leave the verdict as drift when there is a finding. Do not approve the previs gate.
