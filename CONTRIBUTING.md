# Contributing

Ron reviews in plain language. He is learning to code. Write short sentences. The first time you use a term, say what it means. A schema is a checklist for a JSON file. A gate is a switch that makes a stage wait for Ron. A pull request is a proposed change, reviewed before it joins main.

Every pull request updates README.md, ARCHITECTURE.md, ROADMAP.md, and DECISIONS.md when the change affects them. Doc updates ride in the same PR as the code. `docs/` is for supporting material, such as the treatment guide. The living docs stay at the repo root.

Each pull request says what changed and why, in plain language. No secrets and no API keys in the repo. Name an environment variable if the code reads one. Never paste the value.

Never merge your own pull request. Merges happen only on Ron's go.

## Pull request checklist

- [ ] The description says what changed and why, in plain language.
- [ ] A new term is explained the first time it appears.
- [ ] README.md, ARCHITECTURE.md, ROADMAP.md, and DECISIONS.md are updated if this change affects them.
- [ ] Those doc updates are in this same pull request.
- [ ] No secrets, keys, or passwords were added.
- [ ] The checks were run, or the description says what could not be run.
- [ ] This pull request is left open for Ron. The author does not merge it.
